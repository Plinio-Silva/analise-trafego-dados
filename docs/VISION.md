Análise de Tráfego de Dados
Propósito
Sistema web que recebe dados de tráfego de rede coletados ao longo de um dia e gera análises matemáticas e relatórios executivos para auxiliar gestores na tomada de decisão.

Usuário Principal
Gerente de TI.

Objetivo
Transformar dados técnicos em informações gerenciais.

Tecnologia
Java 21
Spring Boot
Thymeleaf
Bootstrap
Maven
Funcionalidades
Importação de CSV
Geração de gráfico
Máximos e mínimos
Crescimento e decrescimento
Interpolação
Taxa de crescimento
Relatório executivo
Alertas de congestionamento
